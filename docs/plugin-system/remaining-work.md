- HLS/DASH/DRM 的已知声明和自适应 MIME 明确拒绝；封面、下载任务错误及会话内重试。
- API 35 转译模拟器已执行真实 IPC、运行时取消/watchdog、Keystore、文件生命周期、

## 推送后的新增实现（未验证）

RC 检查点 `305801a6ce2257d525ac97ecfbf5eeb6291ec667` 已按用户要求推送 main；随后继续补齐：

- 下载任务通过 AtomicFile 持久化，重启后恢复原 SourceId/Track/音质并显示中断/失败及重试入口。
  任务最多100项/1 MiB，不保存解析后的下载 URL、请求头或凭据；旧任务取消不会删除新版重试。
- 插件渐进式下载先写私有 `.part`，完整读取后再提升为完成文件。仅相同插件包/账号会话/音质
  范围且强 ETag/Content-Range 校验通过时追加；200/If-Range 失效重新下载。单文件512 MiB，
  临时文件与并发预留总量1 GiB；取消或移除任务清理临时文件。没有强 ETag 的服务仍支持完整下载。
- 插件调用诊断按来源持久化，最多100条/32 KiB，仅记录固定方法名、受控错误码、时间和耗时，
  不保存参数、脚本日志正文、URL、账号或令牌。设置页可查看/清除。
- 插件账号、目录、收藏和下载入口显示受控中文错误文案；未将异常原文写入诊断。
- 显式重新授权更新原本地账号槽位，不新建重复账号，保留账号 ID 和普通存储；提交绑定发起时
  的账号/凭据版本。成功刷新或替换密文后，会话戳随之变化，旧 Lease 不再恢复有效。
- 有凭据的播放/下载遇到401/403，最多请求一次 OAuth 刷新并重新解析；没有刷新能力时明确失败。
  宿主已知过期、策略改变或无法解密的活动账号返回 expired，未选择账号返回 signedOut。
- 运行时关闭主动取消所属媒体 Broker 和等待中的调用；切换账号/更新/禁用时不依赖下一次读取或
  15秒 socket 超时才撤销。账号操作部分失败也执行运行时撤销。
- 新下载任务保存账号归属摘要；恢复后切到其他账号时拒绝重试，直到切回原账号。创建媒体 Broker
  也复查归属和会话戳。账号表单、收藏对话框及目录页面按来源/Provider 重建，清除旧实例的临时状态。

Android 集中构建与单测已通过；以上受控 HTTP Range/截断/ETag 验收场景**尚未运行**，不是已通过的设备结果。
新补充的延迟媒体响应撤销、同账号重新授权、拒绝/切号/旧凭据写入和任务账号摘要往返场景也未运行。
账号提交在修改凭据前撤销旧 Provider，失败后仅加载新上下文；Manager 回归6/6通过（内存仓库）。
下载索引发布段完成持久写入后才判定提交，取消时清理未提交的完成文件；删除标记不再使后续下载失效。

## 仍未完成的实现与明确限制

- 新版普通存储按来源清整个目录（含已删除账号），v1 迁移及账号单独清理代码已补齐、未验证；
  旧 v1 删除账号的孤儿哈希无法可靠反查，仍保留。卸载保留历史、收藏、下载与公钥记录。
- 发布者信任为本地 TOFU；没有官方 CA、撤销或透明日志。无签名包仍可经明确确认导入，
  签名不证明平台授权、版权、代码安全或发布者现实身份。
- 部分内置 Provider 继续保留 built-in-only 枚举约束；通用路由不得调用这些 getter。仍应按完整
  设备清单确认所有旧页面/菜单，不能仅凭搜索结果为零就宣称全仓动态行为完成。
- 完整字段共享 fixture、Kotlin/Schema 类型变异和真实隔离 QuickJS 全字段 runner 均通过当前子集；
  模型仍为手写映射，尚无代码生成，不能宣称已覆盖所有可能恶意输入。
- 持久诊断、插件主要入口错误中文文案、保守 HTTP 续传与任务重启恢复已补入代码、未验证；
  重启后需显式点击重试，不自动后台联网，弱 ETag/无长度/受限分段范围服务不承诺续传。
- OAuth 仅公开客户端授权码 + S256 + 固定回调；不支持 client secret、OIDC ID Token 验证、
  设备码、私有回调、WebView/Cookie 登录或服务器撤销；待授权 state 不跨进程重启恢复。
- 只支持渐进式音频。HLS、DASH、DRM 不支持；声明/URL/MIME 会拒绝，伪造音频 MIME 的内容
  可能只能在解码时识别为错误，不提供通用 DRM/内容探测。
- 内置远程服务与 LX 在线回归仍需授权环境；3 项既有跳过测试所需外部资源尚未提供。
- 文档站插件指南更新已合并并推送 main，公开站点已读取到更新内容。检查点 `305801a` 已推送；推送后的新增功能仍在本地，
  没有修改正式签名、版本号或创建正式 Release。
