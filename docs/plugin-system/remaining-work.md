## 已补齐的阻塞实现

- 主来源 SourceId、根页面、服务/账号组件；包权限预览与升级扩权批准。
- 包 SHA-256 完整性、可选 RSA 签名、本地公钥/指纹记录、更新/重装换密钥的精确包批准。
- 损坏包隔离/删除隔离副本/重导入；默认保留用户数据，卸载可选清除凭据与已知普通存储。
- 安装前脚本/Manifest 配额、宿主 JSON 深度、IPC 异常收口及严格 HTTP 模型。
- 嵌套歌曲扩展、歌手/专辑身份及未来 metadata 保留；队列完整 Track JSON、下载/推荐
  新旧索引兼容；修复推荐读取时误回退网易云、分析命令未知来源回退及 Spotify 匹配边界。
- HLS/DASH/DRM 的已知声明和自适应 MIME 明确拒绝；封面、下载任务错误及会话内重试。
- API 35 转译模拟器已执行真实 IPC、运行时取消/watchdog、Keystore、文件生命周期、
  Coil 和 Media3 测试子集，以及 SDK 签名 catalog 全部 12 能力的真实 QuickJS/Provider 调用；
  不再是“完全没有设备证据”，也不等于全部原生 UI 完成验收。

## 正式发布前阻塞：仍需完成的设备/安全验收

最新一批功能、故障注入代码和脚本正在按“先实现、后测试”顺序收拢，尚未编译或运行。
受控 OAuth 服务和 runner 已编写，公网受控域名/证书部署及浏览器真实闭环尚未执行。
正常应用服务验收代码、资源故障和进程强杀脚本已编写，同样不能记为 PASS。

1. **API 24 与 ARM 真机**：API 24 镜像已安装，但 AVD 因 userdata 空间不足未启动成功，ABI/应用兼容未验证；实体 ARM64 尚不可用。已有证据仍仅 API 35 x86_64 + arm64 转译。
2. **原生系统全链路**：SAF 文件选择/取消/URI 生命周期、全部能力 UI、返回栈与旧独立账号
   Activity；MediaSession 后台/熄屏/焦点/长音频/401刷新。已测 Media3 是测试播放器，不能代替系统服务验收。
3. **运行时故障与网络红队**：native OOM/栈耗尽、重复调用 FD/线程压测、异常 Binder parcel、
   DNS rebinding、混合 IPv6/socket 抓包、带凭据重定向/媒体端点、全部流式体积/并发边界。
4. **认证**：受控公开 OAuth 测试服务的真实兑换/刷新/取消、升级与切号竞态；Keystore 密钥
   失效/锁状态/密文损坏与写失败。当前已有合成 Keystore 隔离验证和 PKCE/回调 JVM 测试。
5. **持久化故障**：预写决策/旧 trust 快照/启动恢复及进程强杀脚本已实现、未验证；仍需实际
   运行断电/进程死亡/磁盘写失败矩阵及换密钥/签名降级组合。enabled 状态是独立提交，不能宣称全局事务。
6. **旧 APK 数据升级/降级**：已有 codec fixture 与真队列存储测试，未安装真实旧版本做降级；
   下载索引中不可解码旧行、全部未知嵌套集合及后续用户修改仍需完整无损验证。

## 仍未完成的实现与明确限制

- 新版普通存储按来源清整个目录（含已删除账号），v1 迁移及账号单独清理代码已补齐、未验证；
  旧 v1 删除账号的孤儿哈希无法可靠反查，仍保留。卸载保留历史、收藏、下载与公钥记录。
- 发布者信任为本地 TOFU；没有官方 CA、撤销或透明日志。无签名包仍可经明确确认导入，
  签名不证明平台授权、版权、代码安全或发布者现实身份。
- 部分内置 Provider 继续保留 built-in-only 枚举约束；通用路由不得调用这些 getter。仍应按完整
  设备清单确认所有旧页面/菜单，不能仅凭搜索结果为零就宣称全仓动态行为完成。
- 完整字段共享 fixture、Kotlin/Schema 类型变异和真实隔离 QuickJS 全字段 runner 已补齐、未验证；
  模型仍为手写映射，尚无代码生成，不能宣称已覆盖所有可能恶意输入。
- 持久诊断、错误码全面本地化、下载断点续传与任务跨重启恢复未完成；当前任务/错误为会话内状态。
- OAuth 仅公开客户端授权码 + S256 + 固定回调；不支持 client secret、OIDC ID Token 验证、
  设备码、私有回调、WebView/Cookie 登录或服务器撤销；待授权 state 不跨进程重启恢复。
- 只支持渐进式音频。HLS、DASH、DRM 不支持；声明/URL/MIME 会拒绝，伪造音频 MIME 的内容
  可能只能在解码时识别为错误，不提供通用 DRM/内容探测。
- 内置远程服务与 LX 在线回归仍需授权环境；3 项既有跳过测试所需外部资源尚未提供。
- 文档站分支的 PR/合并/部署仍未完成。检查点 `4af356f` 已推送；本轮 RC 修改保留本地，
  没有修改正式签名、版本号或创建正式 Release。
