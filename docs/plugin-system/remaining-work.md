# 未完成与验证边界

此清单区分未编写与未验证，不把 SDK 类型或单元测试当作设备功能证明。

## 尚未完成

1. 主来源持久化及根页面 Home/Explore/Library/Search 已接入 SourceId；服务中心和插件设置可切源。
   仍需设备检查所有返回栈、旧独立 Activity 和账号中心入口的状态一致性。
   跨来源搜索/推荐在插件设置显式选入；聚合搜索已有上下页。
2. 全仓 SourceId 迁移仍需完成；旧 `source` getter 在插件上明确抛错。已迁移主要搜索、
   目录详情、下载列表、歌曲操作、分享、CLI/LAN 身份；LX 与补源明确跳过动态源。
   内置 Provider 内部的枚举约束仍保留，不能将其当作支持动态输入的通用接口。
3. 插件服务/账号组件已接入服务中心与动态主来源设置账号区域；原独立内置账号 Activity 的
   全部导航与展示尚需逐项设备验收。HomeFeed 也可显式纳入本地推荐候选。
4. OAuth 目前仅公开客户端授权码 + S256 PKCE + 固定自定义 URI 回调；不支持客户端密钥、
   OIDC ID Token 验证、设备码、私有 URI 回调配置、嵌入 WebView/Cookie 登录及服务器撤销。
   API Token 过期由插件报告，重新导入；OAuth 按 expires_in 预刷新，也有手动刷新，失败保留
   原凭据。没有自动重放失败写请求。待授权 state 不跨宿主进程重启恢复，需重新发起。
5. 安全图片已接线：带来源的专用 URI、独立 broker、无凭据/重定向/图片缓存、2 MiB 与像素配额；
   图片解码和禁用/卸载后的实际显示需设备验证。HLS/DASH、DRM 不支持。
6. 发布者签名、损坏包管理 UI、持久诊断及错误码完整本地化仍未完成。安装前展示权限，
   升级增加网络/能力或改变认证策略时 Manager 拒绝未批准候选；内存诊断仅保留事件元数据。
   旧账号将凭据策略固定到导入时配置，更新策略变化需要重新授权，不会直接扩展旧 Token 权限。
7. 卸载时普通 storage/凭据清理选项、未知嵌套 JSON 字段的全面无损存储、真正旧版本降级测试。
8. 全部模型生成、全部返回字段的双端恶意输入一致性测试；目前使用显式 Kotlin 校验、
   共享 Manifest fixture、能力方法表一致性和 SDK 标准返回 Schema 测试。
9. 下载菜单显示错误；下载页显示本次会话的任务、错误及取消/重试/移除失败记录，重试重新查询
   当前来源与账号。插件下载并发上限为 2。任务不跨重启恢复，断点续传尚未实现，交互仍需设备验证。
   播放 open 的 401/403/410 已接入最多一次重新解析，不重放账号写请求；真实刷新、Range 偏移
   和 Media3 故障恢复尚未设备验证，不能宣称所有媒体 401 均会自动刷新成功。
