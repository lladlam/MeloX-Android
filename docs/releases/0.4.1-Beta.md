# MeloX Android 0.4.1-Beta

[English](../../README.en.md)

本版本集中修复歌词逐字渲染、账号登录和 Android 构建稳定性，并补齐多来源高级歌词与独立播放账号能力。

## 主要变化

- 支持 AMLL TTML、QQ Music QRC 与网易云 YRC 的逐字、对唱、伴唱、翻译和罗马音歌词。
- 自动选择 AMLL、QQ 音乐、网易云及当前 Provider 的最佳歌词，并支持歌曲与歌词强绑定。
- 修复逐字歌词在罗马音、多行及非高质量模式下变成整行匀速高亮的问题，默认启用高质量渲染。
- 增加网易云、QQ 音乐、酷狗独立第二播放账号，用于音频 URL 和音质探测，不影响主账号资料。
- 修复第二账号登录页面层级、网易云主账号 Cookie 误识别和登录完成协程取消。
- 使用 SF Symbols 子集字体，优化页面过渡、更多操作弹层、MiniPlayer 手势和实时音频波形。
- 修复增量 DEX 丢失 Kotlin 文件类造成的启动崩溃，并调整 D8 构建内存。

## 安装要求

- Android 8.0（API 26）或更高版本。
- 覆盖安装需要设备上的 MeloX 使用相同发布证书；否则请先卸载旧包。
- 音乐平台接口、账号权益、地区限制和 OEM 私有能力可能影响部分功能。
