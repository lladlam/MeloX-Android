# MeloX Android 0.4.4-Beta

## 主要变化

- 增加 Spotify OAuth、网易云与 QQ音乐手机号登录，并完善多来源账号、播放身份和实际音质状态。
- 增加严格的跨平台完整音源回退；只在标题、主艺人和时长匹配时使用已启用来源，不使用试听片段或绕过平台权限。
- 增加用户主动授权、ECDSA P-256 验签、防回滚和白名单约束的音乐源云控，并支持验签公告。
- 云控授权后每次应用进入前台检查，前台持续运行期间每两小时检查一次；后台不执行定时轮询。
- 专辑详情统一使用歌单详情渲染器，搜索歌曲支持双向滑动操作。
- 迁移 Mei 风格的歌曲百科、个人中心、歌手和播客页面，修复深色模式内容色并将主页改为全宽贯通布局。
- 修复 AMLL 歌词优先级、网易搜索时长、歌词等待段渐暗和多来源并发回退。
- 修复单曲空队列下的无尽播放恢复，并提前到队尾歌曲开始时预取推荐。

## 隐私说明

- 云控默认关闭，只有用户明确同意 1.2 版云控隐私协议后才会联网检查和应用签名配置。
- 云控不能下发代码、任意 API、代理地址、广告、遥测或账号数据访问逻辑。
- 关闭云控后停止请求和应用远程配置，并清除已缓存配置。

## 安装要求

- Android 8.0（API 26）或更高版本。
- 覆盖安装需要设备上的 MeloX 使用相同发布证书；否则请先卸载旧包。
- 音乐平台接口、账号权益、地区限制和 OEM 私有能力可能影响部分功能。
