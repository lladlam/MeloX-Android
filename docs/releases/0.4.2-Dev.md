# MeloX Android 0.4.2-Dev

[English](../../README.en.md)

## 主要变化

- Bilibili 音乐源与多来源播放解析改进。
- 统一搜索聚合、同曲去重和来源可用性优化。
- AutoMix 前台/后台预载、队列补充和开关同步修复。
- 私信页面迁移为 Mei 风格的 Grouped List、Liquid Glass 输入栏、资源卡片、时间分组和长按复制。
- 搜索请求改为搜索键或停止输入 1.5 秒后触发。
- 更新检查支持 GitHub Release 与 jsDelivr CDN 优先回退。

## 安装要求

- Android 8.0（API 26）或更高版本。
- 覆盖安装需要设备上的 MeloX 使用相同发布证书；否则请先卸载旧包。
- 音乐平台接口、账号权益、地区限制和 OEM 私有能力可能影响部分功能。
