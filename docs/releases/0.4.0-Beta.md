# MeloX Android 0.4.0-Beta

[English](../../README.en.md)

这是一次业务闭环、界面适配和性能治理版本。正式 APK 仅从本 Release 下载，文件名为 `MeloX-Android-0.4.0-Beta.apk`。

## 主要变化

- 补齐公开/私密歌单创建、从自己的歌单移除歌曲、集合多选下载和逐次音质选择。
- 本地下载可导出到 MediaStore，并可按歌曲、艺术家、专辑和文件夹浏览及修复存储索引。
- 增加十段均衡器、设置搜索、通知歌词模板、存储维护、更新日志、许可和开发者诊断。
- Home/Explore/Library/Search/集合详情适配手机、横屏、折叠屏和平板；补齐高层 Liquid Glass 组件。
- 新增 Classic 播放器外壳；18 套 TextPV 风格使用独立构图、背景、排版和运动参数。
- 停止隐藏页面和暂停状态的无效帧钟/轮询，复用共享网络和媒体缓存，启用 R8、资源收缩、Baseline Profile 与 Macrobenchmark。

完整逐项证据见 [0.4.0-Beta 审计与修复计划](https://github.com/lladlam/MeloX-Android/blob/main/docs/0.4.0-beta-audit-and-remediation.md)，详细更新记录见 [CHANGELOG.md](https://github.com/lladlam/MeloX-Android/blob/main/CHANGELOG.md)。

## 安装要求

- Android 8.0（API 26）或更高版本。
- 第三方音乐接口、账号权益、地区和 OEM 私有能力可能影响部分功能。
- 从旧版覆盖安装时，Android 会校验相同的 MeloX 发布证书。
