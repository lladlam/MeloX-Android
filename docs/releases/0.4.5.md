# MeloX Android 0.4.5

## 主要变化

- 新增酷我音乐原生 Provider，支持搜索、播放、lyricx 歌词解码与手机号验证码登录。
- 自动歌词源优先级统一为 AMLL → QQ音乐 → 网易云音乐 → 当前音乐源。
- 设置 → 外观新增「沉浸式播放」开关，全屏播放器可隐藏顶部状态栏且内容不跳动。
- 歌词长音高光增强：范围扩大 50%、亮度提高 35%、放大动画增强 25%。
- 修复酷狗串台、更新检测、HTTPS 明文请求和 lyricx 歌词解析等问题。

## 隐私说明

- 云控默认关闭，只有用户明确同意云控隐私协议后才会联网检查和应用签名配置。
- 云控不能下发代码、任意 API、代理地址、广告、遥测或账号数据访问逻辑。
- 关闭云控后停止请求和应用远程配置，并清除已缓存配置。

## 安装要求

- Android 8.0（API 26）或更高版本。
- 覆盖安装需要设备上的 MeloX 使用相同发布证书；否则请先卸载旧包。
- 音乐平台接口、账号权益、地区限制和 OEM 私有能力可能影响部分功能。
