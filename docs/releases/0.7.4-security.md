## MeloX Android 0.7.4-security — 2026-11-15

- 版本号：`0.7.4`，`versionCode 29`；发布标签：`0.7.4-security`。
- 产物：`MeloX-Android-0.7.4-security-arm64-v8a.apk`、`MeloX-Android-0.7.4-security-armeabi-v7a.apk`。
- 签名证书：CN=MeloX（SHA-256 `dfcca9865b87a402d341985a48eb132bd8679dfa6d9d502f365dd16210a5ebe9`）。
- 云控签名密钥轮换为 `melox-remote-config-2026-11`；旧 0.7.3 客户端不再信任新云控，需要安装本版本后才能接收新配置。

### 安全与更新

- 新增云控 `securityUpdate` 开关。开启后，带 `-security` 后缀的最新 Release 会触发不可跳过的全量 APK 更新；只走完整安装包，不使用增量补丁。
- 0.7.3 旧客户端仍只能看到普通可选更新，无法被强制；这是旧私钥密码丢失和旧二进制缺少强制逻辑共同导致的限制。
- 修复 Android 10 上播放器流光背景的 `NoClassDefFoundError: android.graphics.RuntimeShader` 崩溃。
- 修复下载任务 `lateinit property job` 崩溃。
- 限制 Bilibili JSON 响应大小和嵌套深度，避免异常响应导致 `JSONTokener` OOM。

### 其他

- 新增 API v1 `resolver` 插件能力及对应设置页、账号页布局。
- 修复一起听单人模式开关在房间刷新后被重置的问题。
- 完整变更见 [CHANGELOG](../../CHANGELOG.md)。

## MeloX Android 0.7.4-security — 2026-11-15

- Version: `0.7.4`, `versionCode 29`; release tag: `0.7.4-security`.
- Assets: `MeloX-Android-0.7.4-security-arm64-v8a.apk`, `MeloX-Android-0.7.4-security-armeabi-v7a.apk`.
- The cloud-control signing key is now `melox-remote-config-2026-11`. Existing 0.7.3 clients do not trust the new key and must install this build before receiving new configs.

### Security and updates

- Added the signed `securityUpdate` cloud gate. When enabled, the latest `*-security` release forces a non-dismissible full-APK update; delta patches are never offered for forced updates.
- Existing 0.7.3 clients still only see the normal optional update. They cannot be forced because the old private-key password was lost and the old binary has no forced-update logic.
- Fixed the Android 10 `NoClassDefFoundError: android.graphics.RuntimeShader` crash in the flowing-light player background.
- Fixed the download `lateinit property job` crash.
- Bounded Bilibili JSON response size and nesting to prevent `JSONTokener` OOM.
- Added the API v1 `resolver` plugin capability and its settings UI; fixed the Listen Together solo toggle being reset by room refreshes.

See [CHANGELOG](../../CHANGELOG.md) for the full list.
