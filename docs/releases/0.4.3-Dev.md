# MeloX Android 0.4.3-Dev

## 主要变化

- 增加持久化音频分析、后台批量分析和媒体预取，提升 AutoMix 候选匹配与过渡稳定性。
- 修复交叉淡化期间暂停、切歌和进度跳转导致的双播放器及 MediaSession 状态错乱。
- 重构多行重叠歌词时间线，保留逐行弹性级联、焦点接位、离屏预布局和长音动态。
- 完善实际播放音质状态及网易云播放缓存隔离，减少账号或音质切换后的陈旧结果。
- 歌单歌曲支持长按操作菜单和双向彩色胶囊滑动；右滑满滑操作可在设置中选择。
- 修复滑动收藏后的“我喜欢的音乐”缓存同步，并统一移除共享玻璃组件外围边框。
- 更新应用启动器图标。

## 安装要求

- Android 8.0（API 26）或更高版本。
- 覆盖安装需要设备上的 MeloX 使用相同发布证书；否则请先卸载旧包。
- 音乐平台接口、账号权益、地区限制和 OEM 私有能力可能影响部分功能。
