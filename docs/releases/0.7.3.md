### 中文

#### 网易云歌曲库与收藏

- 修正 `/api/v3/song/detail` 的单次返回上限：实测 eapi 与 weapi 每批最多只返回 **100 首**，此前误设为 250 导致每批静默丢掉 150 首——歌单只显示约 40% 的歌曲，收藏还要靠串行补漏重试，表现为「又慢又容易超时」。恢复 100 首/批，加入截断识别与自动拆批，补漏改为受控并发。
- 修复「添加到歌单」后歌曲消失（#119）：`playlist/manipulate/tracks` 的真实结果嵌在 `body.code`，外层恒为 200，写入失败被当成成功；`trackIds` 同时改为数字数组。现在失败会明确报错，不再静默丢歌。
- 统一收藏开启时，红心会同时写回网易云，避免下次刷新被服务端真值覆盖而「收藏消失」。

#### 歌词

- 所有音源（含插件源）复用同一条取词、缓存与升级线路。
- 翻译按语言决定：主歌词与系统歌词语言一致时不显示翻译；中文简繁只做字形转换；语言不同才使用翻译，翻译语言不匹配直接丢弃。
- 新增跨源歌词合并：主歌词缺翻译时，从已完成的其它源借用翻译轨道，按 ±120ms 行起始对齐、行数差 ≤1、匹配率 ≥60%，逐字源优先，对不上整份弃用。
- 修复 QQ 逐字歌词（QRC）经常拿不到：首屏逐字等待窗口 2 秒 → 5 秒，并新增 12 秒内「晚到逐字升级」；缓存命中但只有逐行时后台重新解析。
- 伴唱歌词回退到 0.7.2 的亮度行为。

#### 播放器外观

- 流光背景改用 AGSL 在 GPU 上逐像素渲染，并按设备能力自动回退 CPU。
- 保留已渲染帧并在播放器关闭时预热，收起再展开不再重新取色、重算首帧。
- 背景取色复用 Coil 已缓存的封面，不再单独下载解码。
- 自动混音新增「混音时增强背景」开关：饱和度与速度按真实过渡进度平滑升到 2.00x 再回落。
- 「播放器展开 / 收回时长」从「播放」移到「外观 → 播放器外观」，并单独成为「展开 / 收回动画」分类。
- 歌单详情页右上角分享与更多图标缩小到原来的 90%；设置页开关与选项下方的灰色说明文字按需求隐藏。

#### 网络、账号与稳定性

- 只读网易云接口恢复自动重试，写请求禁止重放；退出网易云 / YouTube 不再清空其它音源的 WebView Cookie；网易云资料刷新去重并按 Cookie 校验，避免旧账号响应覆盖新账号。

- 播放服务销毁时释放 DLNA / MiPlay；LAN 传输回到播放器线程读取状态；预取任务切歌取消并使用唯一临时文件；通知封面改为后台解码；vivo 原子岛清理幂等；MCP 空批次返回 Invalid Request。

### English

#### NetEase library and favorites

- Fixed the per-request cap of `/api/v3/song/detail`: both eapi and weapi return **at most 100 songs** per call. The previous batch size of 250 silently dropped 150 songs per request, so playlists showed only ~40% of their tracks and favorites needed a slow serial retry pass. Batching is back to 100 with truncation detection, automatic splitting and bounded-concurrency retries.
- Fixed songs disappearing after "add to playlist" (#119): the real result of `playlist/manipulate/tracks` is nested in `body.code` while the outer object always reports 200, so rejected writes looked successful. `trackIds` is now a numeric array and failures surface as errors.
- With unified favorites enabled, the heart button now also writes to NetEase, so the next refresh cannot overwrite it with the server value.

#### Lyrics

- Every source (including plugins) now shares one fetch, cache and upgrade pipeline.
- Translation is decided by language: none when the main lyric already matches the listener's language, script conversion only for Simplified/Traditional Chinese, and a language-checked translation otherwise (mismatched translations are dropped).
- New cross-source merge: when the main lyric has no translation, a translation track from an already-finished source is merged at ±120 ms line-start tolerance, line-count delta ≤ 1 and ≥ 60% match ratio; word-timed sources are preferred and a misaligned track is discarded entirely.
- Fixed missing QQ word-level (QRC) lyrics: the first-paint word-timing window went from 2 s to 5 s, plus a 12 s late-upgrade path; a line-timed cache hit now re-resolves in the background.
- Backing-vocal brightness restored to the 0.7.2 behaviour.

#### Player appearance

- The flowing-light background is now rendered per pixel on the GPU via AGSL, with an automatic CPU fallback.
- Rendered frames are retained and prewarmed while the player is closed, so reopening no longer re-samples colors or rebuilds the first frame.
- Palette extraction reuses the artwork Coil already cached instead of downloading and decoding it again.
- New "boost during AutoMix" switch: saturation and speed ramp to 2.00x following the real transition progress, then ease back.
- "Player expand and collapse duration" moved from Playback to Appearance → Player appearance, as its own "Expand / collapse animation" section.
- Share and more icons in the playlist detail toolbar are 10% smaller; the grey option footnotes in Settings are hidden as requested.

#### Network, accounts and stability

- Read-only NetEase endpoints retry again while writes never replay; logging out of NetEase/YouTube no longer clears other providers' WebView cookies; NetEase profile refresh is deduplicated and cookie-checked so a stale response cannot overwrite a newer login.
- LAN control connections require the PIN on every reconnect and PCM casting uses a one-time token.
- Plugin uninstall clears private data before removing the entry and erases persistent diagnostics.
- Completed downloads have a total storage quota; the legacy downloader no longer shares `.part` files across pause/resume and enforces a per-file byte cap.
- Playback teardown releases DLNA/MiPlay; LAN transfer reads player state on the player thread; prefetch jobs are cancelled per track with unique temp files; notification artwork decodes off the main thread; vivo atomic-island cleanup is idempotent; empty MCP batches return Invalid Request.
