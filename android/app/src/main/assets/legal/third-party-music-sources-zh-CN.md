# 第三方音乐源使用协议

版本：1.0

生效日期：2026 年 8 月 27 日

本协议适用于你在 MeloX 中主动开启并配置的、由 MeloX 内置音乐服务之外的第三方音乐源。请在开启前完整阅读。若不同意，请不要开启该功能。

## 一、第三方音乐源的性质

- 第三方音乐源不是 MeloX 官方提供、运营、审核或担保的音乐服务。
- MeloX 只提供本地配置入口和必要的调用能力，不代表第三方音乐源获得 MeloX、开发者或任何音乐平台的认可、授权或合作关系。
- 音乐源的名称、接口、服务器、内容、账号体系和服务条款由其提供者自行负责。

## 二、你的责任

- 你应确认自己有权使用所配置的接口、账号和内容，并遵守所在地法律以及相关服务的条款、隐私政策和版权要求。
- 不得使用第三方音乐源绕过付费、地区限制、版权保护、访问控制、账号安全或平台风控。
- 你应自行判断配置来源的可信度，不要填写不必要的密码、验证码、Cookie、Token 或其他敏感信息。

## 三、数据和网络风险

- 使用第三方音乐源时，歌曲搜索词、播放请求、设备网络信息以及你主动填写的配置，可能直接发送给第三方服务器。
- 如果你配置 CHKSZ 等第三方解析服务的个人 API Key，该密钥会保存在 MeloX 本机，并随请求发送给对应服务；MeloX 不会将其发送到 MeloX 云控服务。
- 配置 CHKSZ 前，你需要自行前往 `api.chksz.com` 注册并获取个人 API Key；截至本协议生效日，该服务仅支持 LinuxDo 用户注册，注册资格和服务规则以 CHKSZ 实际页面为准。
- MeloX 不控制第三方服务器如何收集、保存、分析或共享这些信息，也不保证其安全性、隐私性或持续可用性。
- 第三方音乐源可能返回错误、恶意、侵权或不适当的内容、链接和元数据。请在播放、下载或打开链接前自行判断。

## 四、云控范围

- 用户添加的第三方音乐源不在 MeloX 云控范围内。
- 云控不会审核、更新、关闭、修复、替换或远程下发第三方音乐源配置。
- 开启云控、关闭云控或同意云控协议，不代表 MeloX 对第三方音乐源承担任何管理、审查或可用性责任。

## 五、责任限制

在法律允许的范围内，MeloX 和开发者不对第三方音乐源的合法性、准确性、安全性、兼容性、可用性、内容版权、账号状态、数据丢失、网络费用或由此造成的任何直接或间接损失负责。因第三方音乐源产生的争议，应由你与该音乐源的提供者自行解决；法律不得排除或限制的责任除外。

## 六、关闭与撤回

你可以随时在“音乐服务”中关闭第三方音乐源设置。关闭后，MeloX 不再显示或使用用户添加音乐源的入口，但已由第三方服务保存的数据不会因此自动删除，应由你向对应服务处理。

点击“同意并开启”表示你已阅读、理解并同意本协议。协议更新后，MeloX 可能要求你重新确认。
