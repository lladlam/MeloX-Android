# MeloX 云控隐私协议

版本：1.2

生效日期：2026 年 8 月 25 日

本协议单独说明 MeloX“云控”功能的用途、网络访问、可控制范围和你的选择。云控默认关闭，只有在你明确选择“确定”后才会启用。拒绝不会影响未依赖云控的任何现有功能。

## 一、云控的唯一用途

MeloX 云控仅用于音乐源及其下属功能的兼容性管理，包括：

- 在第三方音乐平台接口故障、变更或存在风险时，临时关闭对应登录、搜索、播放、歌词或跨平台回退能力。
- 调整 QQ音乐、酷狗音乐和 Bilibili 等已内置音乐源的回退顺序、排除故障来源和限制请求超时。
- 在 APK 已经内置多个兼容实现时，选择其中一个预置 API 兼容策略。
- 展示与音乐源故障、维护或兼容性有关的单条公告。

云控不会用于广告、收费、赞助推广、用户画像、动态页面布局、远程执行代码或与音乐源兼容性无关的功能。

## 二、远程配置不能做什么

- 不能下发 JavaScript、DEX、Shell、原生代码、反射类名或其他可执行内容。
- 不能下发任意 API、代理、音频、下载或登录地址；只能选择 APK 内预置且经过代码白名单允许的策略。
- 不能读取、修改或上传你的手机号、验证码、Cookie、Token、账号资料、播放记录、收藏、搜索记录、下载内容或本地推荐模型。
- 不能绕过你的本地开关或授权，自动开启你未同意的功能。
- 不能强制付款、跳转赞助、退出应用或封禁本地功能。

## 三、启用后的网络访问

启用云控后，MeloX 会在首帧显示完成后，通过你在更新设置中选择的 GitHub 访问源下载一份经过 ECDSA P-256 数字签名的静态 JSON 配置。此后每次应用从后台进入前台时都会检查一次；如果应用持续保持前台运行，则每两小时检查一次。应用处于后台时不会执行两小时定时检查；再次进入前台时会立即检查。你也可以随时手动检查。

可选访问源包括使用 DNSPod DNS-over-HTTPS 解析的 GitHub 直连，以及 APK 内置的 GhFast、GhProxy 和 GhProxy.org 代理地址。自动模式会使用不含账号信息的公开更新清单测速并选择当前最快的可用源。

GitHub、DNSPod 以及你选择或自动选中的代理服务可能按照其自身政策获取你的 IP 地址、请求时间、User-Agent、目标 GitHub 地址和常规网络日志。MeloX 不会在测速或云控请求中加入账号凭据、播放数据、广告标识符或由 MeloX 生成的用户标识。所有代理地址均固定在 APK 中，云控不能增加或替换代理地址。

## 四、本地保存

MeloX 会在应用私有且不参与系统备份的目录中保存最近一次通过签名验证的配置、ETag、检查时间和防回滚版本号。配置不包含个人信息。你可以在“设置 > 隐私政策与免责声明 > 云控隐私协议与授权”中清除缓存并恢复 APK 内置默认值。

## 五、签名与失败回退

- APK 内置受信任公钥，远程只能提供签名配置，不能替换 APK 的信任公钥。
- 配置签名错误、格式错误、版本回滚、网络失败或不适用于当前 APK 时，MeloX 会拒绝该配置。
- 验证失败时继续使用上一次有效配置或 APK 内置默认值，不阻塞冷启动和本地功能。
- 正在播放的媒体不会因为配置刷新而被立即中断，新规则只应用于后续请求。

## 六、你的选择

- 选择“拒绝”后，MeloX 不会自动请求或应用云控配置，现有体验保持不变。
- 选择“确定”表示你已阅读并同意本协议，允许 MeloX 获取经过签名的兼容性配置，并在白名单范围内远程调整音乐源 API 兼容策略及对应功能状态。
- 你可以随时在设置中启用、撤回同意或重新查看本协议。
- 撤回后，MeloX 停止自动请求和应用远程配置，并清除已缓存的配置；之后可通过软件更新获得新的内置兼容实现。

## 七、开源与第三方修改版

MeloX Android 客户端和公开签名配置可供审查。第三方自行编译版本可以修改或移除云控逻辑，其行为、安全性和配置来源由该版本发布者负责，不代表官方 MeloX。

## 八、协议更新

如果云控用途、数据处理方式或控制范围发生实质变化，MeloX 应更新本协议版本并重新征求你的同意。仅修复文字错误且不扩大处理范围的更新可以不重复弹窗。
